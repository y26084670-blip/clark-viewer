# E3D Viewer

Обновлено: 2026-10-04 01:08 UTC+3.

Версия 4.14.0: крайнее правое положение «Размер точки» включает непрерывную
карту также для плотности энергии ФММ и потерь на токи проводимости;
для областей наблюдения строится цветовая поверхность площадки. Над правым
концом ползунка появился красно-жёлтый треугольник — указатель этого режима.
Начальная палитра 3D — Rainbow. Исправлен контраст поля интервала moview,
флажок «в задании» при открытии отмечен. Окно просмотра GIF можно растягивать
за нижний правый угол, изображение сохраняет пропорции.

Версия 4.13.0: поверхность в GIF сохраняет автоматический подбор высот и
цветовой шкалы. Фильм можно сохранить в `output3XX/demo` флажком «в задании»;
имя содержит короткое обозначение вкладки и дату/время. На первой вкладке
добавлена галерея GIF с просмотром и удалением после подтверждения; её высота
совпадает с 3D-предпросмотром, как в Editor. Диалог записи оформлен в тёмной теме.

Версия 4.12.1: запись GIF учитывает выбранный режим масштаба линейного
графика. При включённом «Авто» пределы пересчитываются для каждого кадра;
при выключенном сохраняется ручной масштаб.

Версия 4.12.0: в 3D добавлен показ «Кроме выделенных». Объёмная карта
учитывает физические границы элементов, в том числе с одним слоем ЭО;
строка состояния показывает фактически построенное представление.
Величины для элементов, областей и виртуальных элементов выбираются
независимо и могут отображаться одновременно. «Не показывать» в этих
списках отключает только результаты соответствующей группы, сохраняя геометрию.
После «Силы / Потери» добавлено меню «Инструменты → Создать moview».
Для динамической задачи оно записывает все шаги текущего вида в GIF:
интервал задаётся перед записью, сохранение предлагается после завершения.
Камера и режим масштаба сохраняются, исходное время затем восстанавливается.
Для временных графиков «Потоки» и «Силы / Потери» перемещается указатель времени.

Версия 4.11.0: добавлены пять палитр и объёмная интерполяция узловых
результатов при максимальном размере точек. Рёбра остаются контрастными при
любой прозрачности геометрии. Поверхности сохраняют ресурсы при смене времени,
«Авто» на рабочих точках и линиях включает и выключает автомасштабирование.
Первая вкладка оформлена в тёмных цветах, список заданий стал контрастнее.

Версия 4.10.0: в 3D добавлена цветовая карта модулей векторов в виде
объёмных точек. Флажок справа от ползунка переключает представление,
ползунок меняет размер точек. Усилен контраст рёбер геометрии.
После загрузки задания автоматически открывается «Источники/Поля 3D».

Версия 4.9.0: в общих опциях 3D выбор «Вид векторов: Тонкие / Объёмные»
применяется к выбранной величине. Убран отдельный показ заданных источников.
Масштаб, цвет и подсказки значений действуют для обоих видов векторов.

Версия 4.8.1: верхние вкладки одинаковой ширины с центрированными подписями;
на узком экране сохраняется горизонтальная полоса прокрутки вкладок.
Убрана постоянная подсказка об управлении мышью над линейными графиками.
Контекстные подсказки со значениями точек сохранены.

Версия 4.8.0: вкладка «Силы / Потери» содержит режимы «Силы», «Моменты» и
«Потери». Последний показывает временной график суммарных мгновенных джоулевых
потерь в ваттах по Q.h5 с учётом объёмов ячеек и симметрий. Для него FM.h5
не требуется; для сил и моментов по-прежнему используется FM.h5.

Версия 4.7.0: базовый каталог проектов может иметь любое имя и расположение;
кнопка выбора — «Выбрать каталог с проектами».
Рабочие точки анизотропной характеристики сохраняют знак H и M также при
нулевых углах анизотропии; вид характеристики определяется по исходной таблице.

Версия 4.6.6: подменю верхних кнопок 3D закрываются щелчком снаружи;
кнопка возвращается в исходное состояние. Щелчки внутри подменю сохраняют его открытым.

Задание можно загрузить для просмотра кнопкой или двойным
щелчком по его строке в списке. Одиночный щелчок выбирает задание для
предпросмотра; во время загрузки повторное чтение не запускается.

На «Рабочие точки» и «Поле на линиях» нажатая кнопка «Авто» поддерживает
автоматический подбор пределов. Выключение кнопки, рамка или перемещение
фиксируют масштаб. Линии и поверхности сохраняют предыдущий кадр до готовности
нового; показанный шаг указан в строке состояния.
При загрузке задания все элементы и области выделены. Ручной выбор сохраняется
при переходе между вкладками.

Сборки `npm run build`, `build:release` и `build:pages` выводят итоговое время
в минутах, также при ошибке; код завершения Vite сохраняется.
Проверены release/pages-сборки и вывод времени при намеренной ошибке конфигурации
на Node.js 24/Linux. Дополнительные параметры после `--` передаются Vite.
