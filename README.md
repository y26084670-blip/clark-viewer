# E3D Viewer

Обновлено: 2026-09-21 17:35 UTC+3.

Браузерный просмотр результатов расчётов clark.AI.

[Открыть E3D Viewer](https://y26084670-blip.github.io/clark-viewer/)

Версия 4.6.6: подменю верхних кнопок 3D закрываются щелчком снаружи;
кнопка возвращается в исходное состояние. Щелчки внутри подменю сохраняют его открытым.

Задание можно загрузить для просмотра кнопкой или двойным
щелчком по его строке в списке. Одиночный щелчок выбирает задание для
предпросмотра; во время загрузки повторное чтение не запускается.

На «Поле на линиях» масштаб подбирается при входе на вкладку,
затем — по кнопке «Авто». Смена времени сохраняет пределы осей и предыдущие
кривые до готовности нового кадра; показанный шаг указан в строке состояния.
При загрузке задания все элементы и области выделены. Ручной выбор сохраняется
при переходе между вкладками.

[Механизм графиков — инструкции для AI](docs/AI_CHART_RENDERING.md).
[Механизм чтения и отрисовки 3D — инструкции для AI](docs/AI_3D_RENDERING.md).

Сборки `npm run build`, `build:release` и `build:pages` выводят итоговое время
в минутах, также при ошибке; код завершения Vite сохраняется.
Проверены release/pages-сборки и вывод времени при намеренной ошибке конфигурации
на Node.js 24/Linux. Дополнительные параметры после `--` передаются Vite.
