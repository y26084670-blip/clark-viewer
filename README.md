## Загрузка задания

Выберите каталог в верхнем списке `clark.*`, затем проект и задание. Одиночный щелчок
по заданию открывает предпросмотр; двойной щелчок или кнопка
«Загрузить для просмотра» загружает результаты и открывает
«Источники / Поле 3D». Во время загрузки повторное чтение не запускается.

Последнее успешно открытое задание и его проект отмечены жёлтым треугольником
вправо с красным контуром. После повторного выбора базового каталога отметки
восстанавливаются; переход к заданию выполняется по решению пользователя.
[Служебные файлы и правила отметки](docs/AI_TASK_SELECTION.md).

Фон первой ячейки списка показывает состояние OM по файлам `input3XX`:
светло-зелёный — есть `om-client.json`, бледно-жёлтый — есть `_om-client.json`,
обычный — нет обоих селекторов. Галочка расчёта независима от этого цвета.
Подсказка сообщает состояние и ошибки доступа. При наличии обоих файлов фон
зелёный, подсказка сообщает конфликт; устраните его в каталоге задания.
После переключения модели в Editor обновите список Viewer кнопкой ↻.

Первые три колонки списка заданий показывают признаки наличия файлов и каталогов:

| Признак | Условие | Подсказка |
|---|---|---|
| Зелёная ✓ | Есть `output3XX/_summary_out.txt` | Решение получено |
| Красная × в первой колонке | Нет `input3XX` | Нет исходных данных: отсутствует каталог input3XX |
| GIF | Есть `output3XX/demo`, в том числе пустой | Созданы GIF анимации |
| T | Есть `comparison` в корне задания | Есть каталог протокола сравнения: comparison. Щелчок — открыть все HTML-протоколы тестов |

✓ и × независимы и могут показываться одновременно. Ошибка доступа оставляет
признак неизвестным; её пояснение доступно в подсказке. После начального чтения
обновляйте признаки кнопкой ↻ справа от заголовка списка: фонового опроса нет.
Обновление сохраняет выделение и прокрутку. Заголовки табличных списков не сортируют строки.

Щелчок по ячейке `T` открывает все `.html` из `comparison` задания и любых
вложенных каталогов. Каждый файл получает свою вкладку в новом окне протоколов;
название вкладки содержит полный относительный путь. Предварительная загрузка
задания не требуется. В самом протоколе доступны его графики и элементы управления;
ссылка «Открыть текущий протокол отдельно» открывает его в отдельной вкладке браузера.
Пустой `comparison` по-прежнему даёт признак `T`; при щелчке выводится сообщение
об отсутствии HTML. Ошибка чтения одного файла показывается рядом с остальными
открытыми протоколами.

Viewer не создаёт и не включает `output3XX/conditions.json` в новые протоколы.
Сохранение условий расчёта исключено из меню и рабочего процесса.
[Существующие файлы и совместимость](docs/AI_TASK_CONDITIONS.md).

## Просмотр результатов

| Вкладка | Содержание |
|---|---|
| Выбор задания | Проекты, задания, 3D-предпросмотр и галерея GIF |
| Источники / Поле 3D | Геометрия, источники, векторы, цветовые карты и векторные линии |
| Рабочие точки | Характеристики M(H) и рабочие точки выбранных ФММ |
| Поле на линиях | Графики модуля и независимо выбранных компонент X/Y/Z |
| Графики | Произвольные зависимости стандартных и ОМ-величин; потокосцепления из `PSI.h5`, силы/моменты из `FM.h5`, суммарные потери из `Q.h5` |

На «Поле на линиях» первоначально включены Модуль, X, Y, Z и «Все локальные
образы». Поверхности площадок и срезов доступны в общей 3D-сцене.

Встроенные выделение всей страницы через Ctrl+A и контекстное меню браузера
отключены. Ctrl+A внутри поля ввода выделяет его текст; команды списков и 3D,
а также контекстные меню и действия правой кнопки, заданные Viewer, сохраняются.

При загрузке все элементы и области выделены. Ручной выбор сохраняется при
переходе между вкладками. Кнопки M, M₀, J, J₀ и Virt в списке «Элементы»
добавляют соответствующие группы к выделению; одновременно можно включить
несколько групп. Повторное нажатие снимает группу, сохраняя пересечения с
другими включёнными группами и ручной выбор вне снимаемой группы.
Пустые группы недоступны.

Над 3D расположены меню «Элементы», «Области», «Симметрии», «Представление»,
«Векторные линии» и «Общие опции». В первых двух меню после выбора величины
доступны «Показать все», «Выделенные в списке», «Кроме выделенных», «Не показывать».
В «Симметрии» находятся флажки локальных, азимутальных, периодических
и зеркальных образов. «Не показывать» скрывает геометрию и результаты своей
группы, сохраняя выбранную величину. «Представление» содержит карту, нормализацию, общий
минимакс и кнопку «Графики». Метод и толщина находятся в «Векторных линиях»,
палитра и тип векторов — в «Общих опциях». Одинаковые ползунки Размер и
Прозрачность стоят после меню, перед «В протокол». При недостатке ширины
строка переносится без перекрытия элементов.
Кнопка «?» в левом верхнем углу 3D открывает легенду цветов объёмных элементов.

Двойной щелчок по вектору или цветному узлу добавляет линию поля через
сохранённый узел. Начало отмечено ромбиком; щелчок по линии, ромбику или
пункту меню выбирает линию. Крестик в «Векторных линиях» удаляет её вместе
с симметричными копиями. Допуск построения фиксирован: 0,1% локального шага
сетки. Окраска по модулю всегда включена. Смена времени пересчитывает линии;
смена задания очищает их набор.

Цветовые шкалы по умолчанию начинаются в нижнем правом углу и растут вверх.
Панели шкал и производительности переносятся за заголовок в пределах 3D-области. Их положение сохраняется при изменении размера, скрытии, смене
вкладки и задания в текущей странице; выбранное положение и порядок шкал учитываются в GIF/WebM.
«Общие опции → Производительность» включает показатели загрузки кадров, расчёта
линий и отрисовки Three.js. Когда флажок выключен, профилирование не выполняется.

## Управление 3D

Обычный режим использует физические клавиши независимо от раскладки:

| Клавиши | Действие |
|---|---|
| X / Y / Z | Вид вдоль соответствующей оси, без изменения масштаба |
| Ctrl+X / Ctrl+Y / Ctrl+Z | Противоположный осевой вид |
| A | Вписать видимую сцену, сохранив текущий ракурс |
| Ctrl+A | Вернуть начальный наклонный вид и вписать сцену |
| ← / → | Предыдущий / следующий шаг времени |
| Пробел (удерживать над 3D) | Линза ×5 радиусом 300 пикселей; колесо меняет только её увеличение |
| Alt+X/Y/Z и движение мыши над 3D | Вращение вокруг глобальной оси через текущий центр вида |
| Shift+X/Y/Z и движение мыши над 3D | Вращение вокруг глобальной оси через начало координат |

Команды вида и времени работают во всей вкладке «Источники / Поле 3D», кроме
ввода текста/чисел, модальных окон и записи GIF. После отпускания Alt осевые
виды блокируются на 0,7 с. Положение камеры, направление, крен, центр вида,
масштаб и проекция восстанавливаются при возвращении на вкладку того же задания.

### Полёт при фиксированном времени

«Общие опции → Полёт» включает перспективное перемещение с захватом мыши, плавным
разгоном и торможением. Вход из ортографического вида сохраняет положение
и масштаб; во время полёта время и переключение обратно в ортографию блокируются.

| Управление | Действие |
|---|---|
| ← / → | Линейное смещение камеры влево / вправо относительно экрана |
| ↑ / ↓ | Приближение / удаление вдоль взгляда |
| Правый Ctrl+↑ / ↓ | Линейное смещение камеры вверх / вниз относительно экрана |
| Shift (левый или правый)+← / → | Вращение влево / вправо вокруг найденного центра |
| Shift (левый или правый)+↑ / ↓ | Вращение вверх / вниз вокруг найденного центра |
| Enter+← / → | Крен против / по часовой стрелке; работает также Enter цифрового блока |
| Мышь | Изменение направления и уточнение центра вращения |
| + / − | Изменение линейной скорости; работают также клавиши цифрового блока |
| 0 | Штатная скорость ×1; работает также 0 цифрового блока |
| ЛКМ | Подлёт к цели под центральным прицелом за 0,5 с |
| Esc | Выход с восстановлением полного вида перед входом в полёт |

Левый или правый Shift задаёт вращение со скоростью 30°/с. При одновременном правом
Ctrl приоритет имеет Shift. Enter с горизонтальной стрелкой задаёт крен
вместо смещения или горизонтального вращения. Объекты смещаются противоположно камере.

Центр вращения — ближайшая видимая поверхность под прицелом. При промахе
сохраняется последнее попадание; до первого попадания вращение идёт вокруг
центра текущего вида.
Мышь уточняет центр без отмены вращения. Центр помнится до конца текущего
сеанса полёта, включая отпускание клавиш, торможение и подлёт.
Новый ручной ввод отменяет подлёт.

Одиночное + умножает скорость на 1,25, − делит на 1,25; удержание плавно
меняет её вдвое за секунду, в пределах ×1/64…×64. Удерживаемый 0 имеет
приоритет. Изменяется скорость всех линейных направлений; масштаб и угол
обзора сохраняются. Новый сеанс начинается с ×1. Текущий множитель,
например «Скорость ×1,25», показывается при регулировке и ещё 1,2 с после неё.

Полёт двигает только камеру: результаты, геометрия и GPU-ресурсы повторно
не создаются, HDF5 не перечитывается. Потеря фокуса, смена задания/кадра или
создание GIF завершает полёт и очищает ввод. Полное восстановление вида
выполняется при Esc или выходе через системный захват мыши.

## Масштабы, GIF и инструменты

«Общий минмакс» использует готовые диапазоны `HEADER/RANGES` за весь расчёт
для выбранных объектов и величин. Флажок общий для 3D, рабочих точек и поля
на линиях; начально включён и сохраняется в текущей странице. Без пригодной
сводки используется диапазон кадра с пояснением причины.

На рабочих точках, поле на линиях и вкладке «Графики» «Авто» поддерживает автоматические пределы;
выключение, рамка или перемещение фиксируют ручной масштаб.
«Инструменты → Создать moview» создаёт WebM (VP9, CRF 30) текущей результатной вкладки.
На «Графики» записывается активный график со всеми его кривыми и маркером времени;
в 3D — сцена с видимыми поверхностями площадок и срезов.
Статическая задача даёт один кадр; динамическая — кадры всех шагов с выбранным интервалом воспроизведения.
Флажок «в задании» сохраняет файл в `output3XX/demo`. Миниатюры, открытый ролик
и предпросмотр готовой записи воспроизводятся автоматически с повтором.
Галерея позволяет максимизировать окно, управлять воспроизведением и удалять файл после подтверждения.
Тёмное меню «Инструменты» содержит только команды: создать moview, создать протокол,
открыть протоколы тестов из `comparison`.

## Документация и сборка

Информацию в панели «Что нового» добавлять или менять только по явному указанию
пользователя. Обычные изменения приложения не требуют новой записи.
Общий журнал Editor и Viewer находится в `data/updates/changes.json`
репозитория [clark-editor](https://github.com/y26084670-blip/clark-editor).
Адрес актуального установщика в «Что нового» читается из `examples-config.json`
на сайте Editor, поле `solverInstallerUrl`, как и в его «Быстром старте».
При открытии панели и проверке обновлений ресурс перечитывается без HTTP-кэша;
прежний адрес из журнала не используется.

- [Чтение и отрисовка 3D, полёт и численные допуски](docs/AI_3D_RENDERING.md).
- [Графики результатов](docs/AI_CHART_RENDERING.md).
- [Глобальные диапазоны HDF5](docs/AI_RESULT_RANGES.md).
- [Создание WebM: сценарий и контракт](docs/AI_MOVIE_EXPORT.md).
- [Галерея GIF и локальные файлы задания](docs/AI_TASK_GIFS.md).
- [Краткое состояние проекта](docs/resume.md).

Установка зависимостей: `npm ci`. Разработка: `npm run dev`.
Проверки: `npm test`. Сборки: `npm run build:release` и `npm run build:pages`.
Pages-сборка использует базовый путь `/clark-viewer/`.
Сборки выводят итоговое время в минутах, включая завершение с ошибкой;
код завершения Vite сохраняется. Дополнительные параметры передаются после `--`.
