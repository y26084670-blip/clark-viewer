# E3D Viewer

## 4.23.1 — уточнение Alt+ось

При наведении на осевой гизмо показывается подсказка об Alt+X/Y/Z. Выбранная ось
вращения остаётся активной всё время удержания Alt, независимо от отпускания клавиши
оси и щелчков мыши. После отпускания Alt команды вида X/Y/Z и Ctrl+X/Y/Z
игнорируются 0,7 с, чтобы случайное повторное нажатие не переключало вид.


## 4.23.0 — осевой гизмо и фиксированное вращение

Тыльная сторона наконечников экранных осей затемнена, чтобы различать направление
оси к наблюдателю и от него. При удержании Alt+X, Alt+Y или Alt+Z движение мыши
вращает камеру вокруг соответствующей глобальной оси через текущий центр вида;
масштаб и центр не меняются.


## 4.22.0 — симметричные образы 3D-результатов

В 3D восстанавливаются отсутствующие AS/PS и зеркальные образы источников и полей
для векторного и цветового представления. Тип зеркала General относится к H/B/M;
для J/E/A используется противоположный тип. Уже сохранённые HDF5-образы не дублируются.


## 4.21.0 — дозапись глобальных min/max в старые HDF5

«Инструменты → Дозаписать глобальные минмакс» добавляет отсутствующий
`HEADER/RANGES v1` в старые `MH/JE/HS/AS/HV/AV/Q.h5` текущего задания.
Существующий индекс любого состояния не перезаписывается автоматически.
Диапазоны вычисляются по всем сохранённым шагам и полной выходной сетке;
исходные массивы результатов не пересчитываются. Каждый файл изменяется во
временной WASM-копии, повторно проверяется и только затем заменяет исходный.
После завершения Viewer переоткрывает результаты, поэтому «Общий минмакс»
становится доступен без повторного расчёта Solver.


## 4.19.0 — компоненты поля на линиях

Во вкладке «Поле на линиях» кнопка «Компоненты» даёт независимый выбор Модуля,
X, Y, Z и одновременные кривые. Начально выбран модуль, пустой набор допустим.
Флажок «За весь расчёт» использует полные глобальные диапазоны HEADER/RANGES
для отмеченных компонент выбранных площадок. При отсутствии подходящей сводки
показана причина, просмотр работает с пределами текущего кадра. Общие пределы
применяются при включённом «Авто» и сохраняются в GIF; ручной масштаб не сбрасывается.
«Поле в областях» остаётся с одиночным выбором. Solver, 3D-симметрии и форматы HDF5
не изменены. Основа глобальных диапазонов 487359b сохранена.

## Подготовлен первый этап — 4.18.0

Фиксированные виды X/Y/Z и Ctrl+X/Y/Z меняют только направление камеры.
A вписывает текущий ракурс; Ctrl+A возвращает начальный наклонный вид и вписывает сцену.
GIF для countTimeSteps=0 содержит один статический кадр без цикла и настройки интервала.
Имена 3D-GIF включают величины (например, M_B_3d_...). Нормировка длин векторов
фиксируется отдельно для величины и задания и не пересчитывается по каждому времени.
Численные значения из HDF5 не умножаются повторно на амплитуду.
Симметричные образы относятся ко второму этапу и здесь не изменены.
Статус проверки: [первый этап](docs/verification/viewer-stage-a.json).
Пакет подготовлен вне репозитория; публикация и браузерная приёмка ещё не выполнены.
