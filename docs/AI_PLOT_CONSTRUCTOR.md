# Конструктор графиков Viewer

Обновлено: 2026-10-18 15:53 UTC+3.

Вкладка «Конструктор графиков» доступна для любого загруженного задания, независимо
от режима решения. Реализация: `src/tabs/PlotConstructor.jsx`,
`src/services/results/plotConstructor.js`, `omResultChannels.js`, подключение `App.jsx`.
[Формат дополнительных каналов](https://github.com/y26084670-blip/solver/blob/main/components/FMI/AI_RESULT_CHANNELS.md)
принадлежит solver; этот документ описывает только чтение и интерфейс.

Пользователь выбирает X и Y: время, стандартная локальная величина M/H/J/E/B/A/Q,
энергетические произведения, потокосцепление катушки, сила, момент, суммарные потери
или параметр модели. Для локального поля указывается номер точки в файле результата
(с единицы); вектор поддерживает модуль и X/Y/Z. Пересчёт единиц выполняется общими
resultMappings/resultHistories. Доступны только файлы с сохранёнными шагами.

До 12 графиков на вкладке; рецепты и добавленные источники сохраняются при смене
вкладки и сбрасываются при открытии другого задания. Общий момент времени показан
маркером. Масштаб, экспорт и подписи используют штатный LineChart. Добавление
источника не меняет уже построенный график. Номер точки относится к порядку файла,
а не к номеру геометрического объекта.

Последний успешный outputOM/latest.json подключается автоматически. «Добавить
параметры ОМ…» читает отдельный каталог с результатами, включая derived-каналы после
обычного полевого расчёта. «Сохранить HTML-протокол» выгружает report.html последнего
ОМ-запуска. Входные JSON и HDF5 не изменяются.

Чтение TSV/JSON ограничено 64 МБ на файл. Проверяются конечность значений, уникальность
столбцов, шаги, время, полнота и доступный fieldRunId. Несовместимый источник
получает ошибку; стандартные каналы остаются доступными. При отсутствии подтверждения
идентификатора выводится предупреждение. XY сопоставляет пересечение сохранённых
шагов, без интерполяции. Точки идут в порядке времени — петля не превращается
в функцию, отсортированную по X.

Проверки: `node --test test/plotConstructor.test.js`; весь набор Viewer;
`node scripts/check-plot-constructor.mjs` с Playwright/Chromium. Браузер проверяет
стандартный канал, произвольную механическую энергию, порядок точек XY и отсутствие
ошибок JS. Реальная механическая модель в Viewer не реализуется.
