# Графики Viewer

Обновлено: 2026-10-28 20:22 UTC+3.

Вкладка «Графики» доступна для любого загруженного задания, независимо от режима
решения. Она объединяет прежний конструктор, «Потоки» и «Силы / Потери».
Реализация: `src/tabs/PlotConstructor.jsx`, `src/services/results/plotConstructor.js`,
`omResultChannels.js`; состояние вкладки принадлежит `App.jsx`.
[Формат дополнительных каналов](https://github.com/y26084670-blip/solver/blob/main/components/FMI/AI_RESULT_CHANNELS.md)
принадлежит solver; этот документ описывает чтение и интерфейс.

## Выбор величин и кривых

Области «Ось X» и «Ось Y» с 4.53.1 используют палитру «Что нового»
(`components/updates/WhatsNewDialog.css`): тёмно-синий фон, светлые подписи,
согласованные поля, списки, кнопки и клавиатурный фокус. Стили ограничены
областями осей; учитываются подсказки, ошибки и недоступные элементы управления.

С 4.61.1 пункты потокосцепления каждой измерительной катушки (`flux`),
суммарной силы (`force`) и суммарного момента (`moment`) выделены жёлтым
фоном `#ffe082` с тёмным текстом `#17202b`. Один шаблон применяется к обоим
спискам X/Y, включая величины другого задания. Выделение определяется видом
канала, а не текстом подписи; локальные поля и подключённые параметры ОМ
сохраняют обычный фон. Проверка стилей включена в
`scripts/check-plot-constructor.mjs` для двух катушек и обеих осей.

Пользователь выбирает X и Y: время, стандартная локальная величина M/H/J/E/B/A/Q,
энергетические произведения, потокосцепление катушки, суммарная сила, момент,
потери или параметр модели. Для локального поля указывается порядковый номер точки
в файле результата с единицы, а не номер геометрического объекта. Вектор поддерживает
автоматическое добавление X/Y/Z без модуля и элемента «Компонента». Единицы пересчитываются общими resultMappings/resultHistories.
Доступны только файлы с сохранёнными шагами.

«Добавить график» создаёт отдельное окно и делает его активным. Расположенная ниже
кнопка «Добавить кривую» добавляет выбранную зависимость в активное окно. Оно
выделено рамкой; щелчок по полю или перевод клавиатурного фокуса выбирает другое
окно. Пока графиков нет, добавление кривой недоступно. У кнопок и полей есть подсказки.

Величины X и Y проверяются отдельно относительно первой кривой активного графика.
Разные величины запрещены даже при одинаковых единицах. Идентичность стандартного
параметра задаёт key, ОМ — модель и column независимо от позиции подключённого
источника. Точка и задание могут отличаться. Единицы не определяют совместимость;
автоматического перевода единиц и дополнительных осей нет.
В раскрываемом списке «Кривые» можно удалить одну зависимость. Удаление последней
закрывает окно. После удаления активного окна выбирается последнее оставшееся.

До 12 графиков. Рецепты содержат массив `curves` с устойчивыми ID и точными ссылками
на источники. Окна keyed по ID графика: добавление/удаление кривой сохраняет Chart.js,
ручные пределы и видимость оставшихся серий. Источник, подключённый позже, не меняет
данные существующей кривой. Ошибка чтения одной кривой выводится явно, остальные
исправные кривые остаются; GIF неполного графика отклоняется.
Рецепты, источники и активный ID сохраняются при смене вкладки и сбрасываются при
открытии другого задания. Масштаб и легенда принадлежат экземпляру LineChart.

«Копировать таблицу» в меню окна выгружает все его кривые в отдельные столбцы.
Во время чтения или при ошибке кривой команда недоступна.
[Общая сетка X, пары X/Y и точность экспорта](AI_CHART_RENDERING.md#копирование-таблицы).

Общий ползунок времени показывает маркеры точных сохранённых значений всех кривых.
Истории не перечитываются при перемещении маркера. XY сопоставляет пересечение
сохранённых шагов без интерполяции, сохраняя порядок времени: петля не превращается
в функцию, отсортированную по X. Номер шага и физическое время доступны в подсказке.

## Пространственные графики

С 4.55.0 вариант «Расстояние вдоль элемента, мм» и его параметры удалены.
Пространственные зависимости доступны как поверхности в «Источники / Поле 3D»:
[площадки и срединные срезы DV1/DV2/DV3](AI_3D_RENDERING.md#surface-graphs).
Тема областей «Ось X»/«Ось Y» и прокрутка длинной подсказки колесом сохранены.

## Подключение результатов ОМ

Последний успешный `outputOM/latest.json` подключается автоматически.
«Добавить параметры ОМ…» открывает тёмное пояснение: нужен каталог одного
выполненного расчёта, например `outputOM/run-…`, с `results.json` и указанной в нём
таблицей TSV. Для старых результатов поддерживаются `run.json` и `currents.tsv`.
Только «Выбрать каталог…» открывает системный picker; начальный каталог — последний
ОМ-запуск или загруженное задание. Ошибка чтения остаётся в пояснении, возможна
повторная попытка. После подключения новые каналы появляются у обеих осей.

Поддерживаются derived-каналы после обычного полевого расчёта.
«Сохранить HTML-протокол» выгружает `report.html` последнего успешного ОМ-запуска.
Входные JSON и HDF5 не изменяются. Чтение TSV/JSON ограничено 64 МБ на файл.
Проверяются конечность значений, уникальность столбцов, шаги, время, полнота и
доступный fieldRunId. Несовместимый источник получает ошибку; стандартные каналы
остаются доступны. При отсутствии подтверждения идентификатора выводится предупреждение.

## GIF и проверки

«Создать moview» записывает только активный график: полные кривые истории и маркер
текущего шага. Масштабы, видимость и исходное время восстанавливаются. Нет общего
сохранённого шага у кривых — запись останавливается с сообщением. Файлы имеют
префикс `graphs`. [Контракт записи](AI_MOVIE_EXPORT.md).

Проверки: `test/plotConstructor.test.js`, `test/browserDefaults.test.js`, весь набор
Viewer и `scripts/check-plot-constructor.mjs` с Playwright/Chromium. Браузерный
сценарий использует настоящие Solid/Chart.js, App и GIF-worker с детерминированным
читателем: проверяет активное окно, несколько кривых, сохранение масштаба, удаление,
подключение ОМ, порядок XY, контекстное меню, локальное Ctrl+A, повторное открытие
вкладки и GIF. Реальная механическая модель в Viewer не реализуется.

## Три компоненты и единственный момент времени (4.44.0)

`expandPlotComponents` разворачивает выбранную зависимость в три рецепта с
разными ID и явными компонентами 0/1/2. Для скалярной оси данные повторяются;
для двух векторных осей пары одноимённые: X–X, Y–Y, Z–Z, без девяти комбинаций.
Энергетические скалярные произведения не разворачиваются. Кривые можно независимо
скрывать через легенду и удалять из состава графика. Существующие низкоуровневые
функции чтения компоненты/модуля сохранены для совместимости, UI модуль не создаёт.

`isSingleTimePlot` выбирает таблицу только при X.kind=time и countTimeSteps=0
у источника Y каждой кривой, включая другое задание. Одна сохранённая точка
при ненулевом количестве интервалов сама по себе не превращает график в таблицу.
Начиная с 4.45.0 каждое добавление создаёт новую строку: groupId объединяет
три компоненты одного добавления. Заголовки — величина и компонента (с единицами),
без номера точки; отдельные колонки «Точка» при наличии и «Комментарий» с путём
задания. Времени и общей строки комментария нет. Удаление компоненты оставляет
пустую ячейку, удаление всех компонент группы удаляет строку. Нули сохраняются.
При чтении/ошибке вместо значений отображается состояние. При смешанном составе
с временной историей остаётся обычный график. Для табличного блока canvas и
адаптер GIF не создаются, общий выбор активного блока сохраняется.

Проверено 2026-10-20: `node --test test/plotConstructor.test.js test/plotTaskSources.test.js`
(15/15), `npm run build:pages`, `scripts/check-plot-constructor.mjs` (14/14).
Браузерный сценарий проверяет настоящие HDF5 workers, сравнение заданий,
сохранение Chart/видимости/пределов при добавлении кривых, буфер обмена,
экспорт GIF, отсутствие выбора компоненты и таблицу вместо canvas при нуле
интервалов, её значения, комментарий, добавление и удаление. Выбор каталогов
эмулируется; данные HDF5, чтение и отрисовка настоящие.

## Управление окнами (4.45.0)

После «Авто» — «Развернуть» / «Свернуть». То же окно dialog переводится в
модальное состояние в пределах видимой области панели; Chart и canvas не
пересоздаются. ResizeObserver и resize окна обновляют размеры. Escape сворачивает,
фокус возвращается кнопке. Во время GIF разворот заблокирован.
Легенда включается отдельным чек-боксом и перетаскивается внутри графика.

Проверки 4.45.0: 704 теста (в том числе 17 профильных), сборка Pages, 16 браузерных сценариев.
Дополнительно проверены перемещение и щелчок легенды, неизменная высота области,
сохранение Chart/масштаба/видимости при развороте, Escape и кнопка сворачивания,
табличное добавление строк, отдельная точка и комментарий, удаление компоненты.
