# Чтение диапазонов результатов Solver

Обновлено: 2026-10-07 16:25 UTC+3.

## Статус

Viewer 4.21.0 читает и использует необязательную сводку `HEADER/RANGES v1`.
Глобальные пределы подключены к «Поле на линиях» и 3D/GIF; «Поле в областях»
пока использует локальный диапазон текущего кадра. Основа формата и читателя —
коммит `487359b`.

В меню «Инструменты» добавлена миграция старых результатов
**«Дозаписать глобальные минмакс»**. Она обрабатывает существующие
`MH/JE/HS/AS/HV/AV/Q.h5` текущего задания только когда `HEADER/RANGES`
полностью отсутствует. Существующие complete/partial/stale/invalid/unsupported
индексы автоматически не перезаписываются.

В 4.21.1 пустые или отсутствующие семейства результатов считаются штатным случаем
и не выводятся пофайлово. Если все имеющиеся данные уже содержат пригодный минмакс,
показывается одна строка: «Файлы уже содержат данные минимакса». Неполные результаты
показываются как «неполные данные». Непригодный существующий индекс показывается как
«минмакс присутствует, но не используется: <краткая причина>».

Миграция читает все сохранённые временные кадры и полную выходную сетку,
вычисляет те же каналы компонентов, модулей и скалярных произведений, записывает
`by_step`, `global`, `step_ids`, `times`, valid/invalid counters и состояние
`complete`. Для MH применимость H и MHdot совпадает с моделью; для JE/Q
неприменимые каналы не превращаются в физический ноль. AS/AV получают
преобразование в единицы отображения ровно один раз.

Файл сначала целиком копируется во временную WASM-FS, там дополняется и повторно
открывается через `Hdf5ResultFile`. Только после успешной валидации временная
копия записывается через `FileSystemFileHandle.createWritable()`; commit замены
происходит при `close()`. При ошибке до close исходный файл не заменяется.
После операции Viewer переоткрывает результаты и использует новые метаданные.

Если часть файлов текущего задания уже содержит корректный complete RANGES,
их единый `run_id` наследуется создаваемыми индексами. Несколько разных
существующих `run_id` блокируют автоматическую миграцию. Если complete RANGES
нет, создаётся общий `viewer-backfill-...` для всех дозаписываемых файлов.

Источники реализации: [resultRanges.js](../src/services/results/resultRanges.js),
[hdf5ResultFile.js](../src/services/results/hdf5ResultFile.js),
[resultRangeBackfillCore.js](../src/services/results/resultRangeBackfillCore.js),
[resultRangeBackfill.js](../src/services/results/resultRangeBackfill.js).

## Интерфейс

```js
import { resultCycleRange } from "./resultRanges.js";
const range = resultCycleRange(task.metadata.JE.ranges, "J", selectedElementIds);
// range.available: true => minimum, maximum, unit, runId, revision, stepCount, state.
// Компонента: {component: "x"} или {component: 0}; по умолчанию norm.
// JEdot/MHdot/Q используют .value; дополнительного коэффициента единиц нет.
```

Матрицы на диске имеют форму `[O,C]` и плоский индекс `o*C+c`.
`object_ids` — номера записей модели, не ЭО и не порядковые позиции выбранного списка.
Компоненты, модули и скалярные произведения являются отдельными каналами.
Для Bs/Bv сохранённый диапазон уже в теслах: повторное умножение на μ0 запрещено.

Индекс проверяет версию, поколение, состав каналов/единиц, тип/IDs объектов,
оси и тип числовых таблиц, полноту времён и счётчики значений. Ошибка необязательного
индекса возвращается в `ranges.reason`, не блокируя обычное чтение файла.
`building`, `stale`, неизвестная версия и отсутствие сводки не дают общего диапазона.
`partial` допускается только с явным `allowPartial:true` и отдельной подписью
«по доступным шагам». NaN/Inf выбранного канала запрещают его автоматический диапазон.
Неприменимый канал не становится фиктивным физическим нулём.

## Оставшееся подключение

При реализации UI использовать этот индекс в общем сервисе диапазонов, а не
дублировать правила единиц в каждой вкладке. Сверять порядок `object_ids` с моделью;
кэш связывать с заданием, runId/revision, величиной и выбранными объектами.
Метаданные снимаются при открытии HDF5; после обновления файлов нужен новый снимок.
Полный проход для старых файлов реализован отдельным инструментом миграции 4.21.0; он запускается только вручную.

Нужно подключить одинаковые пределы к цветным узлам, объёмной карте, поверхности,
геометрической длине векторов и GIF. Отдельно решить шкалу интерполированных линий:
экстремумы узлов не гарантируют экстремумов интерполяции. Не подписывать масштаб
одного кадра как общий и не считать наличие metadata.ranges завершением UI-задачи.
