# Чтение диапазонов результатов Solver

Обновлено: 2026-10-25. Инструменты завершённой миграции удалены из Viewer.

## Статус

Viewer читает и использует необязательную сводку `HEADER/RANGES v1`.
Глобальные пределы за весь расчёт подключены к «Поле на линиях», рабочим точкам и
3D/WebM. Основа формата и читателя — коммит `487359b`.

«Поле в областях» показывает три компоненты X/Y/Z. Только здесь «Общий минимакс»
означает единый диапазон трёх компонент текущего показанного кадра: от наименьшего
минимума до наибольшего максимума. При снятой отметке каждая компонента
автошкалируется независимо. `surfaceComponentRange` получает три сетки из одного
чтения выбранной площадки и LS; индекс `HEADER/RANGES` не используется. Настройка
`areaComponentMinMax` независима от общего флажка остальных вкладок. В WebM правило
применяется заново на каждом шаге.

## Интерфейс

```js
import { resultCycleRange } from "./resultRanges.js";
const range = resultCycleRange(task.metadata.JE.ranges, "J", selectedElementIds);
// range.available: true => minimum, maximum, unit, runId, revision, stepCount, state.
// Компонента: {component: "x"} или {component: 0}; по умолчанию norm.
// JEdot/MHdot/Q используют .value; дополнительного коэффициента единиц нет.
```

Матрицы на диске имеют форму `[O,C]` и плоский индекс `o*C+c`.
`object_ids` — номера записей модели, не ЭО и не порядковые позиции выбранного списка.
Компоненты, модули и скалярные произведения являются отдельными каналами.
Для Bs/Bv сохранённый диапазон уже в теслах: повторное умножение на μ0 запрещено.

Индекс проверяет версию, поколение, состав каналов/единиц, тип/IDs объектов,
оси и тип числовых таблиц, полноту времён и счётчики значений. Ошибка необязательного
индекса возвращается в `ranges.reason`, не блокируя обычное чтение файла.
`building`, `stale`, неизвестная версия и отсутствие сводки не дают общего диапазона.
`partial` допускается только с явным `allowPartial:true` и отдельной подписью
«по доступным шагам». NaN/Inf выбранного канала запрещают его автоматический диапазон.
Неприменимый канал не становится фиктивным физическим нулём.

### Сравнение моментов времени

При чтении `RANGES` допустимо округление времени, в том числе в REAL32:

`|times[i] − step_ids[i] · time_step| ≤ 10⁻⁶ · max(1, |times[i]|)`.

Превышение порога делает индекс непригодным; глобальный диапазон не подключается.
В `resultGlobalScale.js` и `fieldLineComponents.js` дополнительно сверяется
временная сетка задания с тем же коэффициентом 10⁻⁶; масштаб допуска берётся
по ожидаемому времени `i · timeStep`. Поэтому различие порядка 10⁻⁸ с,
вызванное REAL32, само по себе не отключает общий минмакс, а несовместимая
временная сетка по-прежнему отклоняется.

Допуск относится только к сравнению времён. Он не меняет сохранённые данные,
единицы, экстремумы или правила проверки состояния индекса.

Источники: [resultRanges.js](../src/services/results/resultRanges.js),
[resultGlobalScale.js](../src/services/results/resultGlobalScale.js),
[fieldLineComponents.js](../src/services/results/fieldLineComponents.js).

## Использование общего диапазона

UI использует индекс через общий сервис диапазонов без дублирования правил
единиц в каждой вкладке. Сверять порядок `object_ids` с моделью;
кэш связывать с заданием, runId/revision, величиной и выбранными объектами.
Метаданные снимаются при открытии HDF5; после обновления файлов нужен новый снимок.
Индексы `HEADER/RANGES` формируются при расчёте или импорте. Viewer использует готовые индексы; без пригодной сводки доступны диапазоны текущего кадра.

В 3D `applyResultGlobalRange` передаёт общий диапазон в цветовую шкалу слоя
и нормировку длин векторов. Карты, поверхности и WebM используют те же
метаданные отображения. `resultGlobalScale` требует пригодный диапазон для
каждого активного слоя и величины линий, а также общий `run_id`; иначе весь
3D-режим общего минмакса отключается с причиной и остаются пределы кадра.

Для интерполированных векторных линий используется диапазон соответствующей
сохранённой величины. Экстремумы узлов не гарантируют экстремумов интерполяции;
общая шкала не является сертификатом границ интерполированного поля.
За пределами «Поле в областях» не подписывать масштаб одного кадра как общий за весь расчёт.

## Рабочие точки и общий минмакс — 4.25.0

«Рабочие точки» используют готовый глобальный диапазон M выбранных ФММ из
HEADER/RANGES. Для оси M применяется диапазон min(0, Mmin) … Mmax.
Переключатель resultGlobalMinMax общий для вкладок 3D, «Рабочие точки» и
«Поле на линиях», начальное значение true. Настройка принадлежит открытой
странице и не сбрасывается при смене задания/базового каталога.
