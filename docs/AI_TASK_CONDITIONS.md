# Удалённый инструмент условий расчёта

Обновлено: 2026-10-28 20:22 UTC+3.

С Viewer 4.61.1 команда «Инструменты → Сохранить условия расчета» удалена.
Диалог `TaskConditionsDialog.jsx`, сервис `taskConditionsService.js` и их
специализированные проверки удалены. Viewer не запрашивает MPI, не пишет
`clark.conditions-request.json`, не опрашивает `clark.conditions-result.json`
и не вызывает `clark://conditions`.

`output3XX/conditions.json` не участвует в создании протокола, списках DOCS
или меню инструментов. Кнопка «Добавить условия расчёта» удалена ранее,
в 4.61.0. Существующие файлы на диске автоматически не удаляются и не
перезаписываются. Уже встроенный текст старого HTML остаётся частью
пользовательского документа до его явного изменения; новое создание
протокола его не переносит.

[Действующий контракт протокола](AI_TASK_PROTOCOL.md) описывает сводки,
тексты TXT/MD из DOCS, снимки, комментарии и встроенные анимации.

Нативная совместимость `clark://conditions` и старые архивы принадлежат
solver/clark.tests; это изменение Viewer не удаляет команды локального
комплекта и не меняет формат результатов расчёта. Этот файл сохранён как
указатель для прежних ссылок, а не инструкция по использованию инструмента.
