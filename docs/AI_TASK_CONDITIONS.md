# Ручные условия расчета

Обновлено: 2026-10-18 17:01 UTC+3.

Команда «Инструменты → Сохранить условия расчета» доступна для загруженного
задания на любой вкладке и независимо от режима. Компонент
src/components/movie/TaskConditionsDialog.jsx использует тёмный модальный dialog.
Задание передаёт свой дескриптор и rootHandle через Tasks → App; путь вычисляется
rootHandle.resolve(task.handle), а не берётся из выделенной строки или списка запуска.
Повторное открытие результатов после дозаписи RANGES сохраняет rootHandle.

При открытии выполняется только чтение привязки и наличия conditions.json.
Формирование запускается кнопкой «Сформировать»: число MPI-процессов пользователь
вводит явно, без подстановки текущих настроек решателя. Существующий файл требует
флажка замены. src/services/taskConditionsService.js запрашивает write-разрешение
в пользовательском событии, пишет одноразовый запрос и вызывает локальную команду.
Успех показывается только по ответу с совпадающими GUID. Пока запись выполняется,
смена задания и повторное нажатие заблокированы. Тайм-аут означает отсутствие
подтверждения; он не выдаётся за отменённую запись. При закрытии компонента опрос
прекращается. Открытие меню, загрузка задания и запуск расчёта не собирают CPU.

Характеристики описывают текущую машину в момент вызова, дата — формирование файла.
Число процессов введено пользователем. Для перенесённых результатов команда
должна вызываться на машине расчёта. Файл output3XX/conditions.json не требует
ОМ, run.json или готового timing.txt. Существующие входы и результаты не изменяются.

[Нативная команда, привязка, схема файла и одноразовый транспорт](https://github.com/y26084670-blip/solver/blob/main/docs/AI_RUN.md#run-conditions)
принадлежат solver. Нужен обновлённый локальный комплект и повторная привязка
базового каталога через Editor с conditionsVersion=1.

[Архивация timing.txt и необязательного conditions.json](https://github.com/y26084670-blip/clark.tests/blob/main/docs/AI_OM_REGRESSION.md)
выполняется вручную; Viewer и регрессия её не запускают.

Проверки: test/taskConditionsService.test.js — любое состояние загруженного задания,
права, путь, совместимость помощника, явное MPI, замена, подтверждение и отмена опроса.

Фактически проверено 18.10.2026: Node 668/668, сборка Pages; в Chromium —
тёмный диалог на вкладке выбора задания без ОМ, отсутствие записи при открытии,
явный ввод MPI, ожидание подтверждения, флажок замены и отключение без задания.
Браузерный стенд имитирует ответ локального помощника; сам помощник проверяется
отдельным PowerShell-тестом solver.
