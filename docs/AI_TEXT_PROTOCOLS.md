# Текстовые протоколы результатов

Обновлено: 2026-10-30 19:00 UTC+3.

## Сценарий и область

На вкладке выбора задания кнопка «Протоколы...» стоит слева от панели GIF/WebM.
Она открывает модальное окно «Создать / Удалить / Отмена». Обе операции относятся
к выделенному заданию, независимо от загруженного для просмотра. Пофайлового выбора нет.
Без выделения кнопка недоступна. Запись разрешается только после явной команды;
открытие окна не запрашивает разрешений и не меняет файлы.

Управляемый набор в `output3XX`:

| Файл | Источник и содержание |
|---|---|
| `prot-source-J.txt` | JE: координаты, J, E для решаемых объёмов |
| `prot-source-M.txt` | MH: координаты, M, H для решаемых объёмов |
| `prot-field-vtsp.txt` | MH + JE + характеристика ВТСП: H, M, B/μ₀, Jc, E, J, RO |
| `prot-field.txt` | HS: магнитная индукция в заданных точках |
| `prot-fieldV.txt` | HV: магнитная индукция в виртуальных объёмах |

«Создать» обрабатывает все сохранённые временные шаги, включая статический шаг 0.
Повторная команда заменяет файлы целиком. Виды без объектов не создаются;
устаревшие файлы этих видов удаляются после успешной подготовки остальных.
При отсутствии необходимых HDF5 или несоответствии сетки создание завершается ошибкой.
«Удалить» удаляет весь фиксированный набор; отсутствующие файлы допустимы.
Каталог вместо файла не удаляется. HDF5, DOCS, интегральные и служебные протоколы
не входят в набор удаления. Ввод задания и материалы для удаления не нужны.

## Реализация и форматы

`TaskMediaPanel.jsx` связывает команду с handle выделенного задания.
`TaskTextProtocolsDialog.jsx` фиксирует его на время операции, запрашивает запись
непосредственно из обработчика нажатия и блокирует повторные команды.
`textProtocols.worker.js` использует отдельный HDF5-контекст; открытое в Viewer
задание и его reader не переключаются. `taskTextProtocols.js` владеет перечнем,
планированием, форматированием и потоковой записью.

Контракт перенесён из `solver/src/vsolver/01_protocol.jl` на commit `c05e927`.
Заголовки, пробелы, табуляции, единицы, индексы iDTK и порядок строк сохраняются.
Форматы: источники/ВТСП `%13.6E`, координаты поля `%13.6f`, поле `%14.6G`.
Округление десятичных значений соответствует Julia Printf, включая выбор формы G
до округления. Текст — UTF-8 с LF. В полевых протоколах дата относится к созданию
текстового файла; она выводится один раз. Заголовки остальных протоколов также однократны.

Читаются исходные сохранённые компоненты, без прореживания и разворачивания
зависимых образов. Координаты каждого шага берутся из HDF5. Порядок источников:
D1/D2/D3/LS/AS/PS; площадок: LS/n12/n14; виртуальных объёмов — fieldVLayout.
Чтение и проверка HEADER общие с обычным просмотром результатов.
HS/HV уже содержат B в теслах; дополнительное умножение на μ₀ запрещено.

Для ВТСП восстанавливается ось материала с движением и локальной симметрией
соответствующего шага. H и M — проекции на эту ось; J и E — модули векторов.
Jc рассчитывается по сохранённой в `input3XX/xapLibHTS` характеристике и H+M,
RO = E/J, при J=0 — ноль. Сетки и наборы шагов MH/JE должны совпадать.
Промежуточные значения ВТСП приводятся к разрядности сохранённых массивов.

Worker читает и форматирует блоки до 2048 строк, не создавая строку полного файла
или массив «все ЭО × все моменты». File System Access держит незавершённые записи
в отдельных временных файлах. Потоки закрываются после подготовки всего набора;
ошибка чтения/форматирования и отмена до сохранения сохраняют прежние протоколы.
Новые пустые файлы убираются. Во время окончательного сохранения отмена заблокирована.
Общей атомарной замены пяти файлов API не предоставляет: при ошибке закрытия
сообщение перечисляет уже сохранённые файлы.

## Граница с решателем

Solver автоматически пишет `prot-force.txt`, `prot-psi.txt`, `prot-QKV.txt`
и служебные протоколы. Чтение MH/JE/HS/HV ради подробного текста исключено.
Прежняя очистка производных протоколов при новом расчёте сохранена, чтобы старый
текст не описывал заменённые HDF5. Для отключения автоматической записи пяти
файлов требуется новая сборка solver; Viewer работает и с прежними HDF5.
[Контракт solver](https://github.com/y26084670-blip/solver/blob/main/docs/AI_RUN.md#run-protocols).
